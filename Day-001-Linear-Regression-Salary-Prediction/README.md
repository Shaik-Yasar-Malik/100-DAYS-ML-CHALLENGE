# 📈 Linear Regression - Salary Prediction

Welcome to **Day 001 of 100 DAYS OF ML CHALLENGE** 🚀

This project implements a **Simple Linear Regression** model to predict employee salary based on years of experience.

---

## 📌 Project Overview

Linear Regression is a supervised machine learning algorithm used to predict continuous numerical values by finding the relationship between input and output variables.

In this project:

- Input Feature (X): Years of Experience
- Target Variable (Y): Salary

The model learns how experience affects salary and predicts future salary values.

---

## 🧠 Algorithm Used

### Simple Linear Regression

Linear Regression finds the best-fit line between input and output data.

Formula:

Y = b0 + b1X


Where:

- Y → Predicted Salary
- X → Years of Experience
- b0 → Intercept
- b1 → Coefficient
