# 🤖 100 Days ML Challenge

Welcome to **100 Days ML Challenge** — my commitment to learning, building, and sharing Machine Learning projects every day for 100 days.

This repository contains hands-on Machine Learning implementations, data analysis, algorithms, model building, and real-world projects using Python.

---

## 🚀 About This Repository

The **100 Days ML Challenge** is a structured learning journey where I explore Machine Learning concepts from beginner to advanced by building practical projects every day.

### During this challenge, I will cover:

- 📊 Data Preprocessing
- 📈 Exploratory Data Analysis (EDA)
- 🤖 Machine Learning Algorithms
- ⚙️ Model Training & Evaluation
- 🎯 Feature Engineering
- 🧠 Deep Learning Basics
- 📂 Real-world Machine Learning Projects
- 🏆 Model Optimization
